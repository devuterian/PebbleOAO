# Korean translation provenance

Ported from [devuterian/pebble-korean-language-pack](https://github.com/devuterian/pebble-korean-language-pack),
which publishes its new Korean translations under CC0-1.0.
The source message catalog comes from PebbleOS (Apache-2.0).
See the source repository's LICENSE.md and NOTICE.md for full provenance.

This port matches the translatable source strings in Marie PebbleOS based on
v4.37.0 and adds the new palm, charge-limit, dark-mode, weather and vibration
strings. The language pack's GPL generator is not copied into this firmware.
Fonts use the separate OFL-licensed TUMBLED subset with a Galmuri jamo supplement.
