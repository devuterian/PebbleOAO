# 한국어 표시 점검 (2026-09-09)

시스템 앱, 설정, 타임라인, 팝업, 공용 UI와 한국어 번역 리소스를 확인했다.
로그, 내부 식별자, 인증 번호, 사용자가 입력한 제목, 고유명사는 번역 대상에서 제외했다.

## 수정

- 월과 일을 따로 조합하는 날짜 형식의 `%e`에 `일`을 추가했다 (앞선 커밋).
- 테마 강조색의 10개 색상 이름을 번역 추출 대상에 넣고 한국어를 추가했다.
  메뉴는 원래 번역 함수를 호출했지만 색상 이름에 대응하는 번역이 없었다.
- 타임라인 작업 결과의 기본 `Success`에 `완료` 번역을 추가했다.
- 이름 없는 발신자의 기본 `Unknown`도 기존 `알 수 없음` 번역을 사용한다.

## 확인

- 한국어 PO와 에뮬레이터 빌드에서 추출한 POT를 대조했다.
- 한국어 번역에 쓰인 완성형 한글이 내장 TUMBLED 폰트에 있는지 확인했다.
- `msgfmt --check` 통과.
- Obelix 에뮬레이터용 빌드 통과. 리소스 1,975,975 / 2,097,152바이트.
- 이 빌드는 기존 건강 화면 예시 데이터가 있는 검증 전용 작업 폴더에서 만들었다.
  배포용 펌웨어가 아니며, 실제 시계의 모든 화면을 확인한 것은 아니다.

## 휴대폰 앱과의 경계

일출/일몰, 날씨 설명, 일정 참석 버튼, 알림 처리 결과 중 휴대폰이 만드는 문구는
앱 marie-ver005에서 별도로 수정했다. 외부 워치앱과 서버가 보내는 임의의 문구까지
펌웨어가 자동으로 번역하지는 않는다.

## 페블 음성 입력 점검

설치된 앱의 음성 설정은 한국어(`ko`)이며, 생략된 모드의 기본값은 클라우드 전용이다.
marie-ver005 빌드에는 WISPR_AUTH_URL과 KIRINKI_URL이 설정되지 않았다.
코드상 이 상태에서는 해당 클라우드 인식 서비스를 사용할 수 없다.
음성 녹음을 보내는 인식률 실험은 하지 않았고, 사용자가 말한 증상이 페블 음성 입력인지
별도 Wispr Flow 앱인지도 아직 확인되지 않았다. 음성 인식 설정은 변경하지 않았다.
