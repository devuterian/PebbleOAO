# Official app compatibility audit (2026-09-09)

Compared the Marie firmware against PebbleOS v4.37.0 and the companion app
against coredevices/mobileapp master d52101ad3d8940c5aa392d6f224e774cb6f5ce84.
This is a source and targeted-test audit, not certification of every official
app/watch combination.

## Fixed

The dark-mode port changed the SDK status bar's default from white text on black
to black text on white, including legacy SDK 2 applications. Restore the upstream
default in `status_bar_layer_init` and the legacy system status bar. Apps can
still explicitly set their colors. System windows and menus retain their theme.
The new `sdk_default_colors` regression test fails before this fix and passes
after it. The full status-bar, window-stack, system-theme and Obelix dark-mode
suites pass, as does the Obelix emulator firmware build.

## Official firmware return in the companion app

Companion commit 9bacd30e adds a Korean update-source menu for connected Time 2
watches. The choice persists by serial and participates in the update-check cache
key. Selecting a source checks availability; it does not start installation.
While Marie firmware is running, an explicit official-source selection permits
returning to the same or an older official version. Existing downgrade handling
uses recovery when the version number requires it.

Configured official OTA services retain the upstream routing. Public builds
without those service settings use coredevices/PebbleOS's latest stable GitHub
release. Only the exact merged normal obelix_pvt PBZ is eligible; draft,
prerelease, recovery, DVT and individual-slot assets are excluded. The current
v4.37.0 official bundle was downloaded and both slot manifests verified. It was
not installed on the user's watch.

103 companion and 232 protocol-library host tests passed, including source
persistence, official return, asset selection and stock firmware-parser tests.
The release APK passed release lint, packaging and signature verification and
was installed as 1.12.0.1-marie-ver009 (11200008). The process remained running
without a crash in the inspected logs. Full on-phone menu interaction remains
unverified while the phone is locked.

## Compatibility findings and boundaries

- The version parser and preference decoder/DAO match the inspected official
  source. The stock version packet parser preserves the full egg-salad version,
  base 4.37.0 and both normal slot flags; it requires no Marie-only parser patch.
- Standard protocol endpoints and existing language/vibration numeric IDs were
  not renumbered by the ports. Korean is appended as language 10; new vibration
  scores are appended as 15 through 20.
- The official app preserves numeric preference values in storage, but its UI
  maps unknown language/vibration values to its default labels. Choose the added
  language and vibration patterns on the watch. This audit does not claim that
  the unmodified official app gains those menu choices.
- Unknown keys such as chargeLimitEnabled are ignored with a successful BlobDB
  response by the inspected official DAO, rather than aborting synchronization.
- Standard notification logical IDs remain present. The extra Korean app icons
  require the modified app's package mapping; official apps can still deliver
  notifications using their standard icons.
- Korean weather/timeline strings generated by the modified phone app are not
  firmware translations. The official app may supply English Sunrise/Sunset
  and other pin text. Arbitrary incoming notification text is not rewritten.
- Official OTA backends may not recognize private firmware version tags. The
  firmware continues to report its real version; this audit does not disguise it
  as stock or promise official-app OTA acceptance. The explicit return route in
  the companion app is tested separately.
- Pairing, health history, third-party app installation, voice recognition and
  a real official-firmware flash have not all been retested on hardware in this
  audit. Codec and microphone gain were not changed.

The firmware fix is source-only until the next release; the existing egg-salad
release assets are unchanged.
