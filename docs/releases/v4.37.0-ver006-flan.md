* 충전 화면을 입맛대로 바꿀 수 있게 했습니다. 전부 표시, 순정 화면, 아이콘과 잔량만 표시 중에서 골라주세요.
* 충전 중에는 아이콘도 계속 움직입니다. 화면을 닫거나 가리면 애니메이션은 쉬게 했어요.
* 배터리 소수점은 조금 작게, 100%는 깔끔하게 100%로 표시합니다. 시계도 12시간·24시간 설정을 따라갑니다.
* 배터리가 받는 전력과 남은 충전 시간을 한 줄로 보여줍니다. 아직 계산할 자료가 부족하면 계산 중이라고 나옵니다.
* 80% 제한에 도달하면 “충전 완료!”, 충전을 쉬고 있으면 “완충 후 항해 중”이라고 알려줍니다.
* 앱에 프리릴리즈 받기 옵션을 넣었습니다. 경고를 읽고 동의한 분들만 시험 버전을 받습니다. 정식 업데이트 경로도 그대로 쓸 수 있어요.
* 이번 건 프리릴리즈입니다. 충전 전력과 남은 시간은 실제 시계에서 더 확인해봐야 해서, 써보시고 이상한 점이 있으면 알려주세요.
