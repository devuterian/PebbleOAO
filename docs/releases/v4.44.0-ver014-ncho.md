* Core Devices의 최신 `main`(10월 30일 기준)을 합쳤습니다. 업스트림 커밋 1,000개가 넘게 들어왔습니다.
* 운동 앱이 스포츠 워치처럼 데이터 화면 중심으로 새로 바뀌었고, 운동 중 심박 구간 시간과 산소포화도도 기록합니다.
* 방해 금지 시간을 최대 5개 구간으로 나눠 예약할 수 있고, 방해 금지 중에도 알람 소리는 꺼지지 않습니다. 폰에서 무음으로 온 알림은 시계에서도 조용히 들어옵니다.
* 방해 금지에 "기상 시까지"와 "수면 연동"을 넣었습니다. 잠들면 알아서 조용해지고, 일어나면 다시 풀립니다. 건강 기능을 켜야 동작합니다.
* 알람 반복에 "울린 후 삭제"를 넣었습니다. 한 번 쓰고 끈 알람은 목록에서 알아서 사라집니다. 못 듣고 지나간 알람은 지우지 않고 꺼진 채로 남겨 둡니다.
* 빠른 실행에 재생/일시정지, 다음 곡, 이전 곡, 음량 높이기, 음량 낮추기를 넣었습니다. 시계 화면에서 버튼을 길게 눌러 바로 음악을 조작할 수 있습니다.
* 컬러 이모지가 다시 들어갔습니다. 업스트림이 내장 외국어를 빼면서 공간이 생겼습니다.
* 텔레그램 봇 같은 데서 오는 `▓▓▓░░░` 진행 바가 네모로 깨지지 않고 제대로 보입니다.
* 다크 모드에서 알림 목록 종 아이콘이 하얗게 꽉 차 보이던 문제를 고쳤고, 팝업과 대화상자도 다크 모드를 따라갑니다. 테마 메뉴의 겹치던 "배경" 설정은 "다크 모드" 하나로 합쳤습니다.
* 정각 진동과 정각 알림음의 이름을 나눠서 덜 헷갈리게 했습니다. 손바닥으로 덮으면 설정과 상관없이 백라이트가 꺼집니다.
* 알람과 방해 금지 시간을 고를 때 오전/오후 칸이 비어 있던 문제를 고쳤습니다. 업스트림에서 새로 들어온 문구 77개도 한국어로 맞췄습니다.
* 충전 한도에 닿은 뒤에도 충전 애니메이션이 계속 돌던 문제와, 90% 한도에서 충전이 조금 늦게 멈추던 문제를 고쳤습니다.
* 폰 앱도 Core Devices 최신 버전(1.16.0.4)을 합친 `Pebble-1.16.0.4-marie-ver021.apk`로 올렸습니다. 앱 추가 전에 설치 내용을 확인하는 화면이 생겼고, 새로 들어온 문구 40개쯤을 한국어로 맞췄습니다.
* 이번 버전은 Time 2용 프리릴리즈이고 실기기 확인 전입니다. 큰 글씨에서 한국어가 잘리거나, 배터리가 빨리 닳거나, 터치가 이상하면 알려주세요.
